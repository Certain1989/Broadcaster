# Security reports

If you believe you have found a vulnerability in Broadcaster, please use GitHub's **private vulnerability reporting** facility for this repository if available (Security → Advisories → Report a vulnerability). If it is not enabled, avoid posting an unredacted exploit, token or private URL in a public issue; first request a private reporting channel from the maintainer without disclosing sensitive details.

Broadcaster is a hobby project distributed as-is. Reports are appreciated, but there is no guaranteed acknowledgement, response deadline, security-fix schedule or continued maintenance commitment.

Never upload credentials, personal data or authenticated broadcaster URLs. The app contacts external streaming catalogues and launches mpv; their security and availability also matter.
